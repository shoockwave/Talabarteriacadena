# Talabartería Cadena — sitio web

Sitio estático (HTML + CSS + JS). No necesita instalar ni compilar nada.

## Archivos
- `index.html` → debe quedar en la **raíz** del repositorio
- `styles.css` y `main.js` → junto a `index.html`
- `img/` → carpeta con las fotos y el isotipo
- `.nojekyll` → indica a GitHub Pages que sirva los archivos tal cual

## Publicar con GitHub Pages
1. Sube todo el contenido de esta carpeta a la raíz del repositorio.
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. En 1–3 minutos el sitio queda en `https://USUARIO.github.io/REPOSITORIO/`.
